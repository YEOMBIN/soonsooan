# 순수안피부과 홈페이지 가시안

클라이언트 확인용 HTML 시안입니다. 기준 디자인은 Figma `순수안 수정 홈페이지` 섹션(97:26)입니다.
검색엔진 노출 방지(`noindex`)가 켜져 있고, 상담 폼은 실제로 전송되지 않습니다.

## 폴더 구성

```
index.html            페이지 전체 (섹션 01~10)
css/                  섹션별 스타일 (base · header · hero · news · treatment · premium · brand · doctor · about · contact · location · footer)
css/fonts.css         KMU80 · 부크크 명조 서브셋 내장 (파일로 바로 열어도 글꼴이 보이도록)
js/                   섹션별 동작 (main = 공통 스크롤·등장 / hero / news / treatment / premium / brand-water / about / contact / location / footer-reveal)
data/feeds.js         순수안 소식 데이터 (공지사항 · 유튜브 · 블로그)
assets/img/           WebP 이미지 (Figma 원본 그대로, 필터 없음)
assets/fonts/         서브셋 글꼴 원본
_old-2026-10-13/      이전 시안 백업 (이번 가시안과 무관)
```

외부 라이브러리는 CDN으로 불러옵니다: GSAP 3.12.5 + ScrollTrigger, Swiper 11.0.5, Lenis 1.1.13, Pretendard.

## VS Code에서 실행

1. VS Code에서 `soonsooan-site` 폴더를 엽니다.
2. 확장 프로그램 **Live Server**를 설치하고 `index.html`에서 우클릭 → **Open with Live Server**.
   - 또는 터미널에서 `npx serve .` 실행 후 표시되는 주소(예: http://localhost:3000)로 접속합니다.
3. `index.html`을 더블클릭해 파일로 바로 열어도 동작합니다. 단 브랜드 섹션의 물결은 보안 제한으로 배경 굴절 없이 반짝임·색 덩어리만 표시됩니다. 확인은 2번 방식을 권장합니다.

## Vercel 배포

빌드 과정이 없는 정적 사이트입니다.

- **웹에서:** vercel.com → Add New → Project → 이 폴더가 있는 저장소를 선택하고 Framework Preset을 **Other**, Root Directory를 `soonsooan-site`로 지정한 뒤 Deploy를 누릅니다.
- **CLI로:** `npm i -g vercel` 설치 → `soonsooan-site` 폴더에서 `vercel` 실행 (첫 실행 시 질문은 모두 기본값) → 확인 후 `vercel --prod`.
- 배포 주소는 클라이언트 확인용으로만 공유합니다. 정식 오픈 전에는 `index.html`의 `noindex`를 유지합니다.

## 순수안 소식 데이터 갱신 (수동)

공지사항(soonsooan.co.kr/s_4_1), 유튜브 쇼츠(@purelogue), 네이버 블로그(soonsooan)는 외부 사이트라 브라우저에서 직접 불러올 수 없습니다(CORS). 그래서 2026-10-22 기준 실제 게시물을 `data/feeds.js`에 담아 두었습니다. **자동으로 갱신되지 않습니다.**

갱신 방법은 `data/feeds.js`의 각 `items`에 제목·날짜·링크·썸네일을 최신 순서로 최대 5개 넣는 것입니다. 썸네일은 `assets/img/data/`에 넣습니다. 실제 오픈 시에는 서버(XE 게시판 연동)나 서버리스 함수로 자동화하는 것을 권장합니다.

## 섹션별 동작 요약

| 섹션 | 동작 |
|---|---|
| 01 메인 배너 | liet 방식: 7.5초 자동 넘김, 1.25초 크로스페이드, 배경 110%→100%(5.7초), 문구 상승, 진행 바, 일시정지·이전·다음, 스와이프, 슬라이드별 컨트롤 색 |
| 02 순수안 소식 | 탭(공지사항/유튜브/블로그) + 드래그 슬라이드, 진행 바, PC 전용 DRAG 커서, 마지막 카드 '더보기' |
| 03 치료 프로그램 | 호버 시 남색 막 + 제목 위로 + 선 + 설명 (Figma Hover 28:632). 터치: 첫 탭에 열고 다시 탭하면 이동 |
| 04 프리미엄 라인업 | 카드 90% 크기, 끊김 없는 흐름, 호버 시 부드럽게 멈춤, 화살표로 한 칸 이동, 아래 영문은 반대 방향 |
| 05 브랜드 | 앞 섹션 고정 → 브랜드가 위로 덮음 → 글자별 등장. WebGL 물결·윤슬·색 덩어리(마우스 250px 반응, 5~9초 이동), 모바일 2~4초 자동 물방울 |
| 06 의료진 | 브랜드에서 밝은 색으로 넘어가는 짧은 스크롤 전환 + 내용 등장 |
| 07 ABOUT | 카드 아코디언: 호버 120ms 후 펼침, 5초 자동 재생. 태블릿·모바일은 세로 아코디언(탭) |
| 08 빠른상담신청 | 순차 등장, 입력 확인, 연락처 자동 하이픈 (전송 안 함) |
| 09 오시는 길 | 약도에 마우스를 올리면 구글 지도로 전환(처음 한 번만 불러옴). 지도 조작 중에는 닫히지 않고, 바깥을 누르거나 ×로 닫음. 모바일은 탭 |
| 10 푸터 | footer-reveal: 본문이 걷히며 푸터 내용이 내려옴 (768px 이상) |

'동작 줄이기' 설정을 켠 사용자에게는 자동 재생·물결·스크롤 연동 효과를 끄고 정지 화면으로 보여줍니다.

## 확인이 필요한 항목

- 카카오톡 상담·인스타그램 주소: 현재 사이트에서 찾지 못해 푸터 아이콘을 링크 없이 두었습니다 (`index.html` 하단 `foot__sns`).
- 로그인 주소(`index.php?act=dispMemberLoginForm`)가 운영 사이트와 같은지 확인이 필요합니다.
- 울쎄라피 프라임은 상세 페이지가 없어 링크를 걸지 않았습니다.
- KMU80 · 부크크 명조 글꼴의 웹 사용 라이선스를 확인해야 합니다.
- 공지·블로그·유튜브 데이터는 2026-10-22 기준이며 자동 갱신되지 않습니다.
