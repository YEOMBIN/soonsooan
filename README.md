# 순수안피부과 홈페이지 리디자인 — 비공개 HTML 가시안

클라이언트가 디자인과 인터랙션을 확인하기 위한 **비공개 가시안**입니다. 실제 홈페이지가 아닙니다.

- **메인 홈페이지** (`index.html`): Figma 리디자인 시안(97:26)을 퍼블리싱했습니다.
- **상세페이지** (`pages/`): 기존 순수안피부과 홈페이지를 원본 디자인 그대로 복제했습니다 (2026-10-22 기준).
- **로컬 전용입니다.** 이 컴퓨터(127.0.0.1)에서만 열립니다. 외부 배포나 공개 주소는 만들지 않습니다.
- 운영 홈페이지로 이동하거나 데이터를 보내지 않습니다. 상담·로그인 등의 폼은 전송되지 않습니다.

## 1. 실행 방법

아래 세 가지 중 편한 방법으로 실행하세요. 모두 인터넷 없이 동작합니다.
단, 유튜브·블로그·지도 링크를 누르거나 구글 지도를 불러올 때는 인터넷이 필요합니다.

### 방법 1. VS Code Live Server (권장)
1. VS Code에서 이 폴더(`soonsooan-site`)를 엽니다.
2. 확장 프로그램 **Live Server**를 설치합니다.
3. `index.html`을 우클릭하고 **Open with Live Server**를 선택하면 http://127.0.0.1:5500/ 이 열립니다.

`.vscode/settings.json`에 `127.0.0.1` 전용 접속이 설정되어 있어, 같은 와이파이의 다른 기기에서는 접속할 수 없습니다.

### 방법 2. `미리보기 실행.bat` 더블클릭 (Windows)
- Node.js 또는 Python이 설치된 PC라면 http://127.0.0.1:5500/ 이 자동으로 열립니다.
- 종료하려면 검은 창에서 `Ctrl + C`를 누르거나 창을 닫습니다.
- 직접 실행하려면 `node serve.js` 를 입력합니다. `serve.js`는 127.0.0.1에만 연결됩니다.

### 방법 3. `index.html` 더블클릭
서버 없이 바로 열어도 메인 페이지는 정상 동작합니다. 글꼴과 라이브러리가 모두 로컬 파일입니다.
상세페이지도 열리지만, 정확한 확인은 방법 1·2를 권장합니다.

### 클라이언트 검토 방식
- **화면 공유:** 위 방법으로 실행한 화면을 공유해 시연합니다.
- **ZIP 전달:** 이 폴더를 압축한 ZIP을 전달합니다. 받는 분은 압축을 푼 뒤 방법 2 또는 3으로 확인합니다.
- 공개 URL(Vercel, Netlify, GitHub Pages 등)을 이용한 검토는 이번 범위에 포함되지 않습니다. 사용자 승인 없이 진행하지 않습니다.

## 3. 메뉴 · 링크 연결

상단 메뉴는 기존 홈페이지(soonsooan.co.kr)의 실제 메뉴 구조와 같습니다. 모든 항목이 로컬 복제 페이지로 연결됩니다.

| 상위 메뉴 | 하위 메뉴 → 로컬 페이지 |
|---|---|
| 순수안 소개 | 인사말 · 의료진소개 · 시설안내 · 진료시간 / 오시는길 · 보유장비소개 → `pages/about/` |
| 순수안 프리미엄 | 써마지FLX · 악센트프라임(튠페이스) · 이플러스 · 브이로 어드밴스 · 브이빔 퍼펙타 · 피코웨이 · 헐리우드 스펙트라 · 쥬베룩 · 순수안 물광주사 · 벨라소닉 · 아스트로돔페이셜 → `pages/premium/` |
| 시술 및 진료 분야 | 탄력/리프팅/모공 · 주름/보톡스/필러 · 기미/색소질환 · 여드름치료 · 안면홍조/주사 · 흉터/여드름흉터 · 탈모 · 드레싱/냉동치료/피부질환 → `pages/treatment/` |
| 온라인상담 | 온라인상담 → `pages/consult/online.html` |
| 순수안 소식 | 공지사항 · 치료후기 → `pages/news/` |

- 원본 주소와 로컬 경로 전체 목록은 `data/page-map.json`에 있습니다.
- 메인의 치료 프로그램 카드, 프리미엄 장비 카드, 의료진 view more, 소식(공지) 카드, 푸터 약관 링크도 모두 로컬 페이지로 연결됩니다.
- 복제 페이지의 로고, 상단 메뉴, 장비 탭은 로컬 페이지로 연결됩니다. 왼쪽 아래 **'가시안 · 새 메인으로'** 버튼을 누르면 리디자인 메인으로 돌아옵니다.
- 외부 서비스(유튜브, 네이버 블로그, 카카오톡 채널, 인스타그램, 네이버·카카오·구글 지도 버튼)는 누를 때만 새 창으로 열립니다.
- 구글 지도는 외부 연결이라 **자동으로 불러오지 않습니다.** 메인 오시는 길과 복제된 오시는 길 페이지 모두, 약도(버튼)를 눌러야 불러옵니다.

## 4. 섹션별 동작 (메인)

| 섹션 | 동작 |
|---|---|

| 01 메인 배너 | liet 방식 모션은 그대로입니다. PC는 배너 높이가 화면 높이(100svh)에 맞춰져 헤더·배너·컨트롤러가 첫 화면에 모두 보입니다. 피그마 1920×1080 시안(97:479)을 기준 무대로 삼아, 1920×1080 화면에서는 시안 좌표 그대로 보이고, 화면이 낮으면 문구·장비·컨트롤러가 함께 줄어듭니다. 컨트롤러는 화면 아래에서 40~60px 위에 있습니다. |
| 우측 퀵 메뉴 | 피그마 72:130 디자인입니다. 온라인 상담 · 카카오톡 상담 · 오시는 길 · 인스타그램 · 블로그 · TOP 순서이며, PC는 오른쪽에 고정되고 태블릿은 0.85배 크기, 모바일은 화면 아래 가로 바와 둥근 TOP 버튼으로 바뀝니다. 외부 링크는 새 창으로 열리고, TOP은 맨 위로 부드럽게 이동합니다. |

'동작 줄이기' 설정을 켠 사용자에게는 자동 재생, 물결, 스크롤 연동 효과가 꺼집니다.

### 청라빛안과(cheongnabit.com) 분석
- **소스에서 실제로 확인한 기술:** jQuery, GSAP 3.10.4(ScrollTrigger, ScrollToPlugin, DrawSVG), AOS 2.3.1(fade-up/left/right, 1000ms, ease-out-cubic), Swiper 8.4.4, Lenis 1.0.42, SplitType, OverlayScrollbars, 섹션 안 커스텀 커서
- **이 가시안에서 쓴 방식(유사 재현):** GSAP + ScrollTrigger 하나로 AOS 등장과 SplitType 글자 마스크를 직접 구현했습니다. 라이브러리 수를 줄이기 위해 AOS·SplitType은 쓰지 않았습니다.

## 5. 메인 팝업 관리
`data/popups.js` 한 파일에서 관리합니다. HTML은 고칠 필요가 없습니다.
- **켜기/끄기:** `enabled: true` / `false`
- **이미지 추가·삭제·순서:** `items` 목록을 고칩니다. 이미지는 `assets/img/popup/`에 넣고 `width`/`height`에 원본 비율을 적습니다.
- **링크:** 확인된 주소만 `link`에 넣고, 없으면 `null`로 둡니다.
- **오늘 열지 않기:** 이 브라우저의 오늘(현지 날짜) 하루 동안 숨깁니다. X로 닫으면 다음 방문 때 다시 보입니다. 팝업 내용을 바꾸면 `version` 값을 바꿔야 이전 기록과 상관없이 다시 표시됩니다.

## 6. 순수안 소식 데이터 갱신 (수동)
`data/feeds.js`에 2026-10-22 기준 실제 게시물이 들어 있습니다. **자동으로 갱신되지 않습니다.**
각 `items`에 제목·날짜·링크·썸네일을 최신순으로 최대 5개 넣습니다. 썸네일은 `assets/img/data/`에 넣습니다.

## 7. 상세페이지 다시 복제하기
기존 홈페이지 내용이 바뀌었을 때 프로젝트 폴더에서 `node tools/clone-pages.js .` 를 실행합니다(Node.js 18 이상, 인터넷 필요).

실행 후 해야 할 일:
- `pages/about/location.html`의 구글 지도 스크립트를 '버튼을 눌러 불러오기'로 바꿔야 합니다. 현재 파일의 `pv-map` 부분을 참고하세요.
- `data/page-map.json`을 갱신합니다.

## 8. 확인이 필요한 항목
- **울쎄라피 프라임:** 기존 홈페이지 메뉴에 상세페이지가 없습니다. 카드 링크와 CTA를 적용하지 않았습니다.
- **게시판(온라인상담 · 공지사항 · 치료후기):** 목록 화면만 정적으로 복제했습니다. 글쓰기·검색·페이지 이동은 동작하지 않습니다. 공지는 메인 소식 카드에 쓰인 최신 5건만 상세까지 복제했습니다.
- **원본에도 없는 파일:** 일부 글꼴 파일(NotoSansKR)이 운영 서버에서도 없습니다(404). 복제본에서도 콘솔에 표시되지만 화면에는 영향이 없습니다.
- **원본 스크립트 오류:** 시술 및 진료 분야 페이지의 스크립트 문법 오류는 운영 사이트에서도 똑같이 발생하는 원본 오류입니다.
- **메뉴에 없는 페이지:** 숨김 메뉴(뉴테라 리프팅 등 5개, s_1_5)는 현재 메뉴에 없어 복제하지 않았습니다. 누르면 안내만 표시됩니다.
- **글꼴 라이선스:** KMU80 · 부크크 명조의 웹 사용 라이선스 확인이 필요합니다. Pretendard는 SIL OFL입니다.
